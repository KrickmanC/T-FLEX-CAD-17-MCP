Инструменты MCP

tflex_manifest

Манифест набора данных и графа.

tflex_search_symbols

Поиск типов, методов, свойств и событий.

tflex_get_symbol

Получение символа по точному идентификатору.

tflex_search_docs

Полнотекстовый поиск по индексу CHM.

tflex_search_capabilities

Поиск по карте прикладных возможностей.

tflex_get_document

Чтение разрешённого документа по относительному пути.

LOCAL / CONTAINER RUNTIME

Запуск MCP

stdio

npm install
npm run start:stdio

Streamable HTTP

npm install
npm start
# endpoint: http://localhost:3000/mcp

Docker

docker build -t t-flex-cad-17-mcp .
docker run --rm -p 3000:3000 t-flex-cad-17-mcp
